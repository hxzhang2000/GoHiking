
好好设计以下新建计划的页面操作逻辑，你分析一下是否合适：
1. 新建计划分为多个步骤，在页面的上方，出现（1）（2）... 【完成】，类似这样的圆圈数字按钮，用于标记步骤，用户可随意点击切换到某个步骤进行设置，用户点击完成，提示保存计划并命名。
2. 步骤1：选择起点，也是默认的返回点，用户输入文字搜索定位，用户点击地点，标记为起点
3. 步骤2：选择终点，用户输入文字搜索定位，用户点击地点，标记为终点
4. 步骤3：规划爬山路径，分为智能规划和手动规划：
 - 智能规划：调用高德接口智能计算多条步行路径，在地图上用浅蓝色线条画出来，自动选中一条推荐路径，用深蓝色线条画出来；
 - 手动规划：用户按顺序点击多个途径点，每点击一下，就用蓝色线条连接前面的点（或起点），路线自动吸附到道路上，如果没有可吸附的道路，就直线连接。
 - 用户点击规划完成按钮，智能路径就确定为用户选择的路线，手动规划就将最后一个途径点连接到终点，完成路线规划，并保存。
 - 用户切换回此页面时，还可以重新智能选择，或添加、移动、删除途径点，直到再次点击完成按钮，就将调整后的路径保存下来。
5. 步骤4：规划返回路径，分为原路返回、智能规划和手动规划：
 - 原路返回：自动将爬山路径的反向保存为返回路径；
 - 智能规划：调用高德接口计算终点到起点的路径，参照前面的智能规划；
 - 手动规划：参照上山的手动规划，只是方向是反向的
 - 完成按钮起同样的左右，保存返回路径
6. 步骤5：保存，此时弹窗输入规划名称，保存完整的规划
