# 新建计划 · 向导式交互设计（v0.2 完善版）

> 原稿：用户草稿《新建计划》（2026-09-21）。
> 本文在原稿基础上补全状态机、失效联动、边界情况与实现映射，作为「新建计划向导」的实施依据。
> 关联：`prototype/` P-03~P-06 · `docs/DEV-DESIGN.md` §4.8/§5.2 · `docs/PROTOTYPE-ALIGNMENT.md`。

## 0. 目标与范围

- **目标**：把「新建一个计划」拆成 5 个可随意切换的步骤，降低单屏认知负担；
- **范围**：新建走向导；**已保存计划的编辑不走向导**，走计划详情页
  （PlanDetailScreen：拖动起终点 / 重新规划去返程 / 加中间点，能力与向导步骤 3/4 一致），
  避免两套编辑入口漂移；
- **入口**：计划 Tab 的「+ 新建线路」、首页搜索条。

## 1. 页面骨架

```
┌──────────────────────────────────────┐
│ appbar：返回 + 「新建计划」            │
│ ①──②──③──④──⑤            【完成】   │  ← 步骤条（圆圈数字 + 连线；当前步实心蓝）
│                                      │
│            地图（全幅）               │
│   · 起点/终点 marker（可拖动）        │
│   · 候选线（浅蓝）/ 选中线（深蓝）     │
│   · 途经点序号 marker（可拖动/点删）   │
│                                      │
│ 步骤面板（随当前步骤切换）：           │
│   搜索框 / seg 开关 / 操作按钮        │
└──────────────────────────────────────┘
```

- 步骤条：圆圈数字（1~5）横向排列，已完成的步骤实心、当前步高亮、未到步灰置；
  **允许任意点击跳转**（非线性向导，原稿设计 ✓ 保留）。
- 【完成】按钮常驻步骤条右侧；点击时做完整性校验（见 §5），不满足则引导跳转对应步骤。

## 2. 草稿状态机（核心补全）

向导期间的一切操作只落在**会话内草稿**（Draft），不落库；步骤 5 才统一写
`planned_route / planned_leg / planned_waypoint`。**「完成」≠「保存」**——
步骤 3/4 的「完成」只是把该步结果暂存进草稿（原稿两处「保存」表述按此修正）。

| 草稿字段 | 类型 | 步骤 | 说明 |
| --- | --- | --- | --- |
| start | LatLng + 名称 | ① | 必填（完成校验项） |
| end | LatLng + 名称 | ② | 必填（可「与起点相同」，见 §4.2） |
| outbound | 折线 + 距离/耗时 + 来源(智能/手动) | ③ | 暂存；start/end 变更即失效 |
| return | 折线 + 距离/耗时 + 来源(原路/智能/手动) | ④ | 可为空（环线/不返程）；start/end/outbound 变更即失效 |
| name | String | ⑤ | 默认「起点-终点」（现有 routeName 规则） |

**失效联动（原稿未定义，补全）**：
- 步骤① 起点 或 步骤② 终点变更 → `outbound` 置失效（旧线半透明 + 面板提示
  「起终点已变更，请重新规划」）；`return` 同步置失效；
- 步骤③ 去程变更（重新智能选择/手动调整）→ `return` 若为「原路返回」则自动跟随反向，
  若为独立规划则置失效提示；
- 失效不删除旧线（半透明展示供参考），状态图标提示待重做。

## 3. 步骤① 选择起点

四种选点方式（与现有 F-PLAN-01~08 对齐，原稿只写了搜索，补全）：

1. **搜索定位**（原稿）：输入联想（兴趣点 / 公交线路 / 关键词三类结果，F-PLAN-05）；
2. **地图点选**：点击空白处（兜底，永远可用）；
3. **底图 POI**：点白色标签弹「设为起点」（F-PLAN-08）；
4. **当前位置**：面板按钮「用当前位置」（需定位授权）。

选中即标记绿色 marker（可拖动微调，拖动等同重新选点并触发 §2 失效联动）。
面板显示当前起点名；无名称坐标显示「已选点 · 经纬度」。

## 4. 步骤② 选择终点

交互同步骤①（红色 marker）。补两个原稿没有的场景：

- **「与起点相同」快捷项**：一键复制起点为终点（P 型环线徒步常见）；
- **环线提示**：终点≈起点（<80m）时提示「将生成环线，可在步骤④跳过返程」。

## 5. 步骤③ 规划去程

双模式（seg 切换，沿用现有手动规划 直线/吸附 seg）：

### 5.1 智能规划
- 调高德步行多备选（V2 `ALTERNATIVE_ROUTE_THREE` → V1 回退，DEV §4.8.1），
  请求区间 = 起点 →（途经点们，若有）→ 终点 **串行多段**（QPS 约束）；
- 候选以**浅蓝实线**同屏，自动选中推荐（首条），选中线加粗为**深蓝**（原稿 ✓）；
- **候选切换（原稿缺，补全）**：地图下方横排候选 chips「方案 A · 最优 / B · 最短 /
  C · 缓坡」（命名按 DEV §4.8 语义），点 chip 切换选中；点击地图候选线同样可选中；
- 距离/耗时/爬升（估算）随选中候选显示。

### 5.2 手动规划
- 按顺序点地图加途经点（上限 50，F-PLAN-28），相邻点连线：优先吸附道路，
  无路则直线（现有 ManualConnect 直线/吸附两种模式 seg 保留）；
- 途经点 marker 可**拖动**微调、**点击 marker 删除**（F-PLAN-27 删除确认）；
- 「撤销上一个 / 清空」按钮（现有 F-PLAN-25）。

### 5.3 「完成」（本步暂存）
- 智能模式：以当前选中候选写入草稿 outbound；
- 手动模式：把最后一个途经点连接到终点完成整线（原稿 ✓）。**边界**：一个途经点
  都没点时，「完成」= 直接对 起点→终点 做一次智能规划（避免出现无意义直连线；
  若规划失败则提示并保持未完成态）；只有途经点、没点终点？终点必填于步骤②，不存在此态；
- 完成后面板显示该线距离/耗时/爬升（估算）摘要 + 「重新智能选择」「继续手动调整」入口。

## 6. 步骤④ 规划返程

三种方式（原稿 ✓ 保留，补边界）：

| 方式 | 行为 | 备注 |
| --- | --- | --- |
| 原路返回 | 去程折线反向写入草稿 return | 现有 returnBack() 一键完成 |
| 智能规划 | 终点 → 起点调用高德（不含去程途经点） | 参照 §5.1，候选 chips 同款 |
| 手动规划 | 按顺序点地图加返程途经点，方向从**终点**出发（参照 §5.2 反向） | 完成时把最后途经点连回**起点** |

- **「不规划返程」**（补全）：环线徒步（终点=起点）或只想存去程时，可点「跳过返程」，
  return 为空；计划列表/详情显示「单程」。
- 「完成」= 本步结果暂存草稿（同 §5.3 语义）。

## 7. 步骤⑤ 保存

1. 弹命名对话框：默认名 = 起点名-终点名（同名环线 = 「起点环线」）；可改、可加备注（可选）；
2. 保存动作（现有 savePlan 同事务口径）：
   - `planned_route`：totalDistance/totalAscent/totalDescent 汇总；
   - `planned_leg`：OUTBOUND / RETURN 两段（polylineJson 抽稀 ε=8m 落库）；
   - `planned_waypoint`：手动途经点落表（orderIndex 顺序；**现状缺口**：规划链路此前
     不写该表，向导手动中间点补写，与导入导出 F-IO-21/F-PLAN-43 打通）；
3. 爬升用 DEM 重评（H-06：不可用落 null，绝不编造；difficulty 距离+爬升重评）；
4. 成功 → 提示「已保存」→ 返回计划 Tab（列表 Flow 自动刷新）；保存后的调整走**计划详情页**。

### 完整性校验（【完成】按钮）
| 缺失 | 行为 |
| --- | --- |
| 无起点 / 无终点 | 跳转对应步骤 + 面板红字提示 |
| 去程未规划 | 确认框「尚未规划线路，仅保存起终点？」（允许，回退方案） |
| 返程未规划 | 静默通过（单程合法） |

## 8. 边界与异常

| 场景 | 处理 |
| --- | --- |
| 无网 / 规划失败 | 提示失败原因；智能模式引导切手动（F-PLAN-20 原则：不出现空白页） |
| 定位未授权 | 「用当前位置」置灰 + 点击提示（不阻塞搜索/点选） |
| 候选仅 1 条或 3 条重复 | 距离差 <5% 去重（DEV §4.8），如实展示 | 
| 返回键 | 草稿有内容时确认「放弃本次新建？」；无内容直接返回 |
| 语言/单位切换 | 沿全局设置，草稿不受影响 |

## 9. 与现有实现的映射（工作量评估）

| 能力 | 现状 | 差距 |
| --- | --- | --- |
| 搜索联想 / 地图点选 / POI 选点 / 当前位置 | ✅ PlanScreen | 向导复用即可 |
| 智能多候选 + 浅蓝/深蓝高亮 | ✅ PlanScreen（候选横排卡） | 改为 chips + 面板内嵌 |
| 手动点途经点 + 吸附/直线 + 撤销 + 点删 | ✅ PlanScreen | 复用 |
| 原路返回 | ✅ PlanDetailScreen.returnBack | 复用 |
| 起终点 marker 可拖动 | ✅ PlanDetailScreen | 复用 |
| **向导容器 + 步骤条 + 草稿状态机 + 失效联动** | ❌ 无 | **需新建**（本设计主要增量） |
| 多段串行规划（起点→途经点→终点） | ✅ PlanDetailViewModel.replanOutbound | 复用 |
| 途经点落 waypoints 表 | ❌ 规划链路未写 | 补写（与 F-IO-21/43 打通） |

## 10. 验收清单

- [ ] 步骤条五步可任意往返，状态不丢失；
- [ ] 改起点后，去程/返程线变半透明并提示重新规划；改回原点后恢复；
- [ ] 智能规划出 ≥2 条候选时 chips 可切换，选中线深蓝加粗；
- [ ] 手动模式：吸附/直线切换生效；无路区域直线连接；点 marker 可删；
- [ ] 零途经点点「完成」→ 自动对起终点智能规划，失败提示不落草稿；
- [ ] 原路返回 = 去程逐点反向；重新规划返程与去程独立；
- [ ] 环线（终点=起点）可跳过返程，列表显示「单程」；
- [ ] 【完成】校验：缺起/终点引导；缺去程需确认；
- [ ] 保存后计划 Tab 立刻出现新计划，详情页可继续编辑；
- [ ] 断网时手动规划仍可用（仅高程标注「—」）。
